原型 · iPad 文件交接 / 回传
推荐形态：文件面板内联回传卡（轻量确认，不弹层）+ 回传收件箱（多个待回传 / 历史记录，全屏子页停靠内容区）。 v1 只列 PDF；回传只另存副本到 iPad 批注/，不覆盖原文件。
形态说明 / 为什么这样设计

A 文件面板内联回传卡（推荐）：单文件回传是「看一眼文件 + 确认一次」的轻量动作，直接在当前文件面板展开，不弹层、不打断上下文。文件名可改，保存位置固定。

B 回传收件箱（全屏子页）：多个待回传、历史记录、离线队列属于独立任务，进内容区停靠的全屏子页（侧栏不动）；与现有 FullPage 的平板落位口径一致。

C 底部抽屉：禁用。项目 UI 硬规则明确不做 bottom sheet，回传不需要例外。

只另存副本：Prodrafts 导出可能是单页/已扁平化/格式转换后的 PDF；覆盖原文件有数据损失风险，v1 统一落 iPad 批注/，原文件保留。

v1 只列 PDF：交接层先收窄到 Prodrafts 的主路径；其他文件类型后续按同一通道扩展，不影响本形态。
